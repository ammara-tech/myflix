🎬 MYFLIX – Movie Finder & Interactive Cinema App

A Netflix-inspired web application that lets users search for movies and shows, save favourites, explore genres, and play an interactive cinema-style movie guessing game — all inside a cinematic UI experience.

Built using HTML, CSS, and JavaScript, powered by the TVMaze for live movie/show data and localStorage for saving favourites.

 Features
🔎 Movie Search Engine
Search movies and TV shows in real time
Powered by TVMaze API
Displays posters, titles, and release years

❤️ Favourites System
Save and remove favourite movies
Stored in browser using localStorage
Persistent across sessions

🎭 Genre Explorer
15+ genres including Action, Drama, Sci-Fi, Horror, etc.
Filter results dynamically by genre
Interactive genre descriptions

🎮 Movie Guessing Game
Guess movies and TV series from hints
Two modes: Movies & Series
Score system + streak bonuses
Hint system with penalties

📺 Cinema Mode (TV Experience)
Full-screen cinematic video player
Auto-binge mode (continuous playback)
Genre-based film selection system
Play / Next / Binge controls

🎨 Netflix-Inspired UI
Smooth horizontal scrolling rows
Hover zoom + spotlight effects
Dark cinematic theme
Responsive layout for mobile

🛠️ Tech Stack
HTML5
CSS3 (Advanced animations + Netflix-style UI)
JavaScript (Vanilla)
TVMaze (Movie data source)
LocalStorage (Favourites system)
